# ---------------------------------------------------------------------------
# HSL (MA57) linear solver for IPOPT  -- requested for speed
# ---------------------------------------------------------------------------
# IPOPT ships *inside* the casadi wheel and defaults to the MUMPS linear solver.
# To make IPOPT use the (much faster) HSL MA57 solver you must point it at your
# HSL shared library. No extra pip package is required; the solver is selected
# in userOpts.py via:
#
#     opts["ipopt"]["linear_solver"] = "ma57"
#     opts["ipopt"]["hsllib"]        = "/path/to/libcoinhsl.so"   # or libhsl.so
#
# Alternatively (if you do not want to set 'hsllib') make the library findable
# on the loader path before launching Python:
#
#     Linux:   export LD_LIBRARY_PATH=/path/to/hsl/lib:$LD_LIBRARY_PATH
#     macOS:   export DYLD_LIBRARY_PATH=/path/to/hsl/lib:$DYLD_LIBRARY_PATH
#     Windows: add the HSL bin folder to PATH
#
# The library file is commonly named libcoinhsl.so (CoinHSL bundle) or libhsl.so.
# If casadi's bundled IPOPT was not built with the HSL loader, install a
# coinhsl-linked IPOPT/casadi build. The framework falls back to 'mumps' with a
# warning if 'ma57' cannot be loaded, so it always runs.
